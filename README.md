# Telegram-бот расписания колледжа

Бот на Python для расписания politex59.ru. Пользователь выбирает группу, а бот отправляет отдельную PNG-картинку с занятиями выбранной группы.

## Что умеет
- выбор и сохранение группы для каждого Telegram-пользователя;
- кнопки «Сегодня», «Завтра», «Вся неделя»;
- создание читаемой картинки из Excel;
- загрузка Excel-файлов администратором через Telegram;
- попытка найти ссылки на расписание на сайте колледжа.

## Важно про Облако Mail.ru
Ссылки `cloud.mail.ru/public/...` не всегда предоставляют прямую ссылку на Excel: иногда страница формируется JavaScript-ом. Поэтому автоматическое получение файла из облака зависит от текущей разметки Mail.ru. Надёжный резервный способ уже встроен: администратор отправляет боту Excel-файл документом и указывает день в подписи, например `Вторник`. Файл сохраняется как `data/Вторник.xlsx`.

Можно заранее добавить публичные ссылки в `schedule_links.json`:
```json
{
  "Понедельник": "https://cloud.mail.ru/public/...",
  "Вторник": "https://cloud.mail.ru/public/..."
}
```
Если Cloud.Mail.ru не отдаёт прямой файл, используй загрузку через Telegram.

## Установка на компьютере/VPS

Требуется Python 3.11 или новее.

1. Создай бота через `@BotFather` и скопируй токен.
2. Распакуй архив и открой папку проекта.
3. Установи зависимости:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. Установи переменные окружения:
   - Windows PowerShell:
     ```powershell
     $env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
     $env:ADMIN_IDS="ТВОЙ_TELEGRAM_ID"
     python bot.py
     ```
   - Linux:
     ```bash
     export BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
     export ADMIN_IDS="ТВОЙ_TELEGRAM_ID"
     python bot.py
     ```
   `ADMIN_IDS` — твой числовой Telegram ID. Если оставить пустым, команды загрузки будут доступны всем, поэтому обязательно задай его для реального использования.

## Как загрузить расписание
1. Напиши боту `/start`.
2. Выбери группу.
3. Отправь команду `/upload`.
4. Отправь файл Excel документом, а в подписи укажи день: `Понедельник`, `Вторник`, `Среда`, `Четверг`, `Пятница` или `Суббота`.
5. Нажми «Сегодня» или «Завтра».

Файлы расписания хранятся в `data/`. Если запускаешь бота на бесплатном хостинге с временной файловой системой, после перезапуска файлы могут пропасть — нужен постоянный диск или VPS.

## Команды
- `/start` — начать;
- `/group` — сменить группу;
- `/today` — расписание на сегодня;
- `/tomorrow` — расписание на завтра;
- `/upload` — подсказка по загрузке Excel.

## Безопасность
Не публикуй токен бота и не отправляй его в чаты. Если токен случайно утёк, перевыпусти его в `@BotFather`.
